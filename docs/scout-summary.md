# Scout summary

This is the public-safe summary of the first curation pass for the `sana.ai.dev` hub. Full evidence stays local; this page records decisions, not claims of publication.

## First local batch

- **Dashboard collector** — not published. It is a private LAN operations pipeline tied to internal infrastructure and personal workspace data.
- **Xara toolbelt** — published as a redacted write-up, not a code drop, after Sana nominated it as the first project. Strong internal proof supports the claims; environment-specific state, desktop captures, outbox records and restore snapshots stayed local. See [projects/xara-toolbelt/README.md](../projects/xara-toolbelt/README.md).
- **Pi SSH skill** — not published. It is an internal operational playbook tied to a private host and a local key path.

## External ecosystem study

A metadata-only scan of the Claude Code plugin/skill ecosystem produced a shortlist for study: official plugin manifests, persistent memory patterns, governed hook/config patterns, ledger/handoff orchestration and hook-event observability. No external repository has been cloned, installed or adapted. Every external artifact must pass scan, approval and exact-version pinning first.

## Next decision

Sana has nominated xara-toolbelt as support material, not as a flagship. Further projects need a new nomination; external repositories still require the sourcing gate before any clone or install.
