# project-sol

Public hub for `sana.ai.dev` projects, verified tools and evidence-backed write-ups.

## Who it is for

Builders who want the reasoning, the evidence and the limits alongside a project — not just a polished screenshot.

## Requirements

Nothing to install: this repository is documentation and curation. See [getting started](docs/getting-started.md).

## Quick start

```bash
git clone https://github.com/sana-ai-dev/project-sol.git
cd project-sol
```
